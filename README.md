Python Calculator - UKK RPL Project

A simple calculator built with Python and Tkinter for the Ujian Praktek Rekayasa Perangkat Lunak (UKK RPL).

Features:
✔ Basic operations (+, -, *, /)
✔ Percentage (%) calculation
✔ Clear (C) and decimal (.) support
✔ History display for full calculation
✔ Dark-themed GUI

How to Run:
Install Python 3.x

Run main.py

Developed as a practical exam project for Software Engineering (RPL).
